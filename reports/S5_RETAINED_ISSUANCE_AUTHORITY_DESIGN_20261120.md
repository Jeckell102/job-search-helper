Proposed additive DDL for `main.ordinary_live_issuance_admissions` follows. The primary key gives one lifetime allowance per dispatch across every candidate, policy, root and retry. `binding_json` holds the closed slot binding, which contains digests, integer bounds, and the original absolute deadline. Keeping those exact canonical bytes lets restart recover the original deadline and independently verify their digest. `selection_sha256` binds the separately reviewed owner selection and coordinator/runtime pins. The row needs one mutable state group.

```sql
CREATE TABLE IF NOT EXISTS main.ordinary_live_issuance_admissions (
    dispatch_sha256 TEXT PRIMARY KEY NOT NULL
        CHECK (length(dispatch_sha256) = 64 AND dispatch_sha256 NOT GLOB '*[^0-9a-f]*'),
    binding_sha256 TEXT NOT NULL
        CHECK (length(binding_sha256) = 64 AND binding_sha256 NOT GLOB '*[^0-9a-f]*'),
    binding_json BLOB NOT NULL
        CHECK (typeof(binding_json) = 'blob' AND length(binding_json) BETWEEN 1 AND 4096),
    selection_sha256 TEXT NOT NULL
        CHECK (length(selection_sha256) = 64 AND selection_sha256 NOT GLOB '*[^0-9a-f]*'),
    root_dev INTEGER NOT NULL CHECK (typeof(root_dev) = 'integer' AND root_dev > 0),
    root_ino INTEGER NOT NULL CHECK (typeof(root_ino) = 'integer' AND root_ino > 0),
    boot_id TEXT,
    started_unix_ms INTEGER,
    started_elapsed_ns INTEGER,
    deadline_elapsed_ns INTEGER,
    reservation_sha256 TEXT CHECK (
        reservation_sha256 IS NULL OR
        (length(reservation_sha256) = 64 AND reservation_sha256 NOT GLOB '*[^0-9a-f]*')
    ),
    commit_sha256 TEXT CHECK (
        commit_sha256 IS NULL OR
        (length(commit_sha256) = 64 AND commit_sha256 NOT GLOB '*[^0-9a-f]*')
    ),
    expired INTEGER NOT NULL DEFAULT 0 CHECK (typeof(expired) = 'integer' AND expired IN (0, 1)),
    CHECK (
        (reservation_sha256 IS NULL AND boot_id IS NULL AND started_unix_ms IS NULL
         AND started_elapsed_ns IS NULL AND deadline_elapsed_ns IS NULL AND commit_sha256 IS NULL)
        OR
        (reservation_sha256 IS NOT NULL AND boot_id IS NOT NULL AND length(boot_id) = 36
         AND typeof(started_unix_ms) = 'integer' AND started_unix_ms > 0
         AND typeof(started_elapsed_ns) = 'integer' AND started_elapsed_ns >= 0
         AND typeof(deadline_elapsed_ns) = 'integer' AND deadline_elapsed_ns > started_elapsed_ns)
    )
);
```

### Transactions and monotonic state

- **Enroll.** A private entry point reachable only by the measured application owner inserts one exact canonical row with an empty state group. An identical repeat reads the existing state, including its spend or expiry. A conflicting selection, binding, root or deadline holds. Existing rows are immutable in their enrollment columns. Use an exact read and insert under `BEGIN IMMEDIATE`, following the existing intake pattern.
- **Transact.** Open one verified coordinator connection in existing-file `mode=rw`. Reuse the store's WAL, FULL durability and context-managed commit. Inside `BEGIN IMMEDIATE`, read the exact row from `main`, check the enrolled pins and run the slot callback against that record. Validate the returned transition, update only the mutable state columns with an exact old-state predicate if anything changed, and verify the same record before commit. The method returns only after a successful commit. The existing connection helper opens a creatable path, so add an issuance-specific verified existing-file option while preserving existing callers. A lock timeout, I/O error or unavailable schema holds the exact attempt. This callback does bounded local clock and record checks in the final transaction. The callback has no access to SQL or to provider, app-store, or scheduler operations.
