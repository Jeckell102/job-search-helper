## Entry contract

Call `freeze_selected_temporary_retry_fixture_locked(sink, state, runtime_binding, cycle_id=..., fixture_provider=...)` under the inherited scraper lease and writer lock, in that order. Pass the original outcome's selected sink, the canonical read-only State and Jobs views, and the runtime identity from pre-import admission. The entry verifies the exact consumed outcome against its durable receipt and archive, the one spent dispatch budget, the request fingerprint and one-company immutable State/mirror, and the current Company owner and source. Existing release and retained-work holds, a populated request slot, unrelated unfinished work, and prior ordinary inventory or exact local/sync artifacts for this cycle stop execution. The current Company check joins the original event to its eligible durable revision and requires that revision to be latest. A newer A→B→A revision holds even when the Company's canonical source hash returns to A. The exact ordinary State stays queued and retains the original source fact and revision.

The entry writes a durable `CLAIMED` record before invoking the synthetic provider. A verified board-matching result gets an atomic `FROZEN` record containing the full inventory, timestamps, inventory digest, and the pinned cycle, request, runtime and original outcome. A completed write survives lost acknowledgement. Restart after a provider interruption or a failure before the freeze returns `HELD_FETCH_UNCERTAIN` with the budget spent. Source drift after a result preserves the frozen bytes and returns `HELD_SOURCE_CHANGED` with the inventory digest. The ordinary inbox, Jobs, State and Sheets stay read-only during this entry. The fixture journal is available at `selected-retry-fixture-inventory/<cycle>.json` within the disposable state directory.
