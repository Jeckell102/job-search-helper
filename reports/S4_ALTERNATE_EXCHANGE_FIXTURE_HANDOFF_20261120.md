# Disposable alternate checkout exchange handoff

Implemented and exercised a Linux same-parent exchange controller and a read-only witness in the private fixture lane. Every accepted endpoint is an explicit direct child of the fixture's `checkouts` directory under `/tmp/jsh-s4-alternate-exchange.1z4uM591/fixtures/<fixture>`. The API rejects outside paths, symlinked directories and separate or nested mounts. There is no production CLI or site-checker integration. [Controller](/tmp/jsh-s4-alternate-exchange.1z4uM591/exchange.py:85)

## Change from the design

The unprivileged fixture returned EACCES when `renameat2(RENAME_EXCHANGE)` moved a mode-0500 sentinel across two parents. Linux requires write permission on a directory moved across parents. The same-parent exchange passed with the sentinel still mode 0500. The fixture therefore reserves a hidden `.exchange-park-*` sibling for each original and keeps journal files in a separate private control directory. This replaces the earlier assumption of a parked tree under a separate private parent. Actual host launcher discovery must exclude the parked names, including recursive discovery and Python fallback. Any launch account able to search the shared parent and access the original directory may be able to reach its parked name. If separate private parking is essential, it requires a separately reviewed design. [Exchange and replay](/tmp/jsh-s4-alternate-exchange.1z4uM591/exchange.py:235)

## Fixture API and evidence

- `FixtureExchange(root, [(canonical, hidden_sibling), ...]).prepare()` seals every pair, generation, parent identity and lock identity before any swap. Pins include owner, group, mode, device, inode and mount ID. Each sentinel must already exist, be empty and have mode 0500. Preparation interrupted before the durable journal may leave an orphan fixture lock and fails closed. [Preparation](/tmp/jsh-s4-alternate-exchange.1z4uM591/exchange.py:195)
- `close()` checks the whole ordered placement vector and accepts the durable prefix or exactly one observed next exchange. It syncs the parent and durably replaces the journal for each step. Resume syncs the journal directory before advancing if the preceding process died after replacing the record. Successful return provides generation and intent digest. [Closure](/tmp/jsh-s4-alternate-exchange.1z4uM591/exchange.py:268)
- `witness('closed' | 'restored')` takes a shared nonblocking lock and reads journal and directory evidence without creating controls or changing placements. It attests visible exact placement, rather than drain or proof that an interrupted writer completed its final sync. On uncertain writer exit, obtain a successful controller return before using witness evidence for release. [Witness](/tmp/jsh-s4-alternate-exchange.1z4uM591/exchange.py:293)
- `restore(evidence_bytes, verify_terminal=callback)` requires an external affirmative verification before the first reverse swap and on replay. Supply a read-only verifier that authenticates terminal proof against the closed generation and intent digest, and proves authority to reopen. The callback receives `(ExchangeProof, evidence_bytes)` and runs under the exclusive exchange lock. It must avoid re-entering this API. Reverse intent includes the proof hash and is synced before the first reverse swap. A different proof or a failed verifier halts replay. [Restore](/tmp/jsh-s4-alternate-exchange.1z4uM591/exchange.py:274)

Thirteen fixture cases passed under the workspace user. They include actual child-process exit after forward and reverse swaps, exit after progress record replacement before sync, parent and endpoint substitution, missing and symlinked endpoints, occupied sentinels, out-of-order placements, read-only witness behavior, and terminal-proof denial and replay. The tests model process crash and resumed visibility. They do not establish power-loss durability for the target host filesystem or continuity across a changed mount namespace. The site still needs independent writer drain, supported-route and namespace coverage, the required release checkpoints, and durable external terminal evidence. No actual checkout, production route or service was changed. [Fixture tests](/tmp/jsh-s4-alternate-exchange.1z4uM591/test_exchange.py:61)
