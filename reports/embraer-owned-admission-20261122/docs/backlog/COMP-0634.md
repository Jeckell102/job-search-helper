# Embraer U.S. public careers integration

Embraer's corporate careers page links its U.S. openings to the employer
tenant at https://embraer.breezy.hr/. The same page links other regions to
separate providers. Keep the U.S. tenant and existing posting IDs.

The current Breezy fallback requires a single page-level h1. Three current
public posting details have a separate heading inside the employer brand
link and then the exact job title in the banner, with an exact metadata
URL and one nonempty full description. The installed scraper returns a
typed partial for this layout. The focused synthetic test models it.

Adapt the visible-detail parser for this one employer. Preserve the current
behavior for other boards, the canonical posting URL and exact title, and
the full-description and inventory-reread checks. Preserve the typed hold
for pages with a genuinely unverified identity or unavailable content.
Test the scoped behavior through normal Breezy dispatch and run the shared
board regression tests. Save the candidate for independent validation.
