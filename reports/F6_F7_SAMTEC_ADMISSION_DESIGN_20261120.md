# Sprint 3 Samtec admission design

The installed retained path requires disjoint companies. Its existing authorization binds historical evidence. The planned Samtec request requires a versioned operator-only admission, separate exact authorization and the existing retained publication lifecycle.

- Use the normal scheduler's effective unfinished-cycle calculation. Seal the raw cycle rows and supersession evidence. Require the sole effective blocker to match the approved retained cycle.
- Admit one exact operator request and durable receipt. Bind the Company ID and source revision, selected queued historical membership entry, current local and remote Company controls, source identity, workbook profile, runtime and expiry. Permit the selected same-ID match only with verified unstarted state. Continue checking other-company aliases.
- Prove absence of selected-company inventory, plans, progress, claims and unresolved publication ownership across the sealed cycles before invoking the provider. Reserve and protect the request before the fetch. Recheck returned provider identity. Store the complete frozen inventory so recovery can reuse it.
- Preserve every historical cycle, inbox and Company row, including Samtec's historical ownership pointer. Use normal job staging and filters for selected Job History and Job Evidence operations. Hold on prior-job closure, unapproved edits, ambiguous records or operations outside scope. Bind each operation and retain exact local commit and remote confirmation evidence.
- Reconcile claimed remote delivery by readback after lost acknowledgement. Protect manual choices, salary estimates, intervening changes and matching records. Keep the durable operator request through publication. Consume only the exact completed request with an independently verifiable receipt. Preserve broad processing and general release controls.

The admission worker owns the effective-blocker calculation and checks before fetch. The planner worker owns the isolated opt-in planner containment and tests. The release identity reviewer owns the architecture for the source, configuration and dependency pin through recovery. The coordinator integrates the versioned route after the prerequisite interfaces stabilize. Independent QA must verify the whole staged route and all existing guards. A future live authorization must bind the new scope. The current v1 preview is diagnostic.
