## Blocking evidence

1. **A malformed failure becomes verified zero.** A signed, admitted Samtec fixture returned complete empty inventory with the supported zero marker and a malformed access-denial envelope. The freeze step replaced the nonempty envelope with null. Publication then recorded VERIFIED_ZERO and completed State. Reject a non-null malformed failure at the inventory boundary, or retain its invalidity and hold settlement. A genuine absent failure must remain distinguishable. 2. **The Greenhouse zero proof accepts an unrelated returned host.** The direct terminal decision returned the same VERIFIED_ZERO for an approved Greenhouse API endpoint and an unrelated fixture host with the same board slug and claimed ATS. The shared provider identity drops the hostname when the supplied ATS says Greenhouse, and the selected fetch and terminal checks both use that identity. Require a recognized returned provider endpoint as well as the pinned board identity. Preserve supported Greenhouse endpoint variants. [Provider identity](/tmp/jsh-s4-terminal-qa.RB31bCop/src/job_search_helper/retained_work_exception.py:93) · [Terminal source comparison](/tmp/jsh-s4-terminal-qa.RB31bCop/src/job_search_helper/selected_retry_terminal.py:111)

Immediate replay refused the same result because the durable frozen record no longer matched. Reread and compare the durable parent, dispatch and frozen identities after the workbook boundary and before Jobs effects. The test simulated local file corruption in the read window. It did not imply that other supported writers can bypass the held locks.
