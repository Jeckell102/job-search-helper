checks for the exact listener. The supported release command started at
10:50 Eastern, closed the three named alternate checkout routes, then

stdout and stderr. No controller process receipt, exit record, refusal

marker or scraped data change occurred. The assistant bridge recovered

full original protected-state readback. It preserved the failed attempt
verbatim. The controlled exchange restored all three original checkout
